# Установка Malevich одной командой

Установщик рассчитан на Raspberry Pi с Klipper и Moonraker и плату STM32F407VE.
Запуск:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/CyrilVG/malevich_mode/main/install.sh)
```

Скрипт проверит комплект и serial-порт FT232R, остановит Klipper, сохранит полный
дамп flash STM32 и сначала прошьёт AutoDetect v0.6.0. До запуска диагностики он
попросит подтвердить, что двигатели и нагреватели физически отключены. Затем
попросит проверить PE14 мультиметром: ожидается около 3,3 В, без перегрева или
аномального тока. После одного диагностического прохода скрипт покажет найденную
модель и предложит выбрать X или XL, отметив результат AutoDetect. Можно вручную
переопределить результат с дополнительным подтверждением.

AutoDetect нужен только для определения модели. После выбора он будет заменён
Klipper BIN для выбранной модели. Файлы прошивки X и XL хранятся отдельно и
проверяются по SHA256; сейчас это одинаковый образ Klipper, поскольку переключение
банка драйверов XL реализовано настройкой `select_pins: PC3` в конфигурации, а не
отдельным патчем прошивки STM32.

## Подключение SWD

При выключенном питании подключите SWD, затем подайте штатное питание на плату
STM32. Не соединяйте VCC Raspberry с VCC платы. FT232R должен быть подключён к
Raspberry. На Pi 3/4/5 отключите SPI0, так как он использует GPIO8/GPIO11.

| Одноплатник | SWCLK | SWDIO | Земля | Статус |
| --- | --- | --- | --- | --- |
| Raspberry Pi 3 | pin 23 / GPIO11 → PA14 | pin 24 / GPIO8 → PA13 | pin 20 → GND | Поддерживается |
| Raspberry Pi 4 | pin 23 / GPIO11 → PA14 | pin 24 / GPIO8 → PA13 | pin 20 → GND | Поддерживается |
| Raspberry Pi 5 | pin 23 / GPIO11 → PA14 | pin 24 / GPIO8 → PA13 | pin 20 → GND | Поддерживается |
| Orange Pi 3 LTS | — | — | — | GPIO-профиль пока не проверен |
| Orange Pi 5 | — | — | — | GPIO-профиль пока не проверен |
| Orange Pi 5 Plus | — | — | — | GPIO-профиль пока не проверен |

Orange Pi показываются в меню, но прошивка пока остановится без изменений: для
них не подтверждены распиновка GPIO и профиль OpenOCD.

## Конфигурация принтера

После обнаружения модели установщик спрашивает, одно или два сопла у принтера.
Для двух сопел готового профиля пока нет, поэтому текущий `printer.cfg` будет
сохранён; обновятся только MCU-прошивка и панель. Профили принтеров и макросы
разделены: в профиле `printer.cfg` подключается отдельный `macros.cfg`, а карта
выводов находится в `board_pins.cfg`.

Профили X устанавливаются из комплекта. XL-профиль добавляет переключение банков
TMC2209 через штатный `select_pins` Klipper. Он основан на приложенном черновике:
его 4 Z-драйвера не совпадают с тремя адресами второй банки, проверяемыми
AutoDetect v0.6. Поэтому перед заменой XL-конфига установщик показывает это
расхождение и требует отдельное подтверждение. Если вы его не подтверждаете,
текущий конфиг остаётся без изменений.

При установке профиля сохраняются копии заменяемых файлов. Для сохранения
текущей осевой конфигурации используйте `--keep-config`. Для ручного выбора
модели без AutoDetect предназначен `--skip-autodetect --printer-model X|XL`.
Это аварийный/отладочный режим; обычный запуск сначала определяет модель.

Для проверки комплекта без прошивки используйте `--check --printer-model X|XL`.
Если FT232R подключено несколько, укажите точный serial-путь:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/CyrilVG/malevich_mode/main/install.sh) \
  --serial /dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A9WERABX-if00-port0
```

Установщик запускается от пользователя Klipper, например `pi`, без `sudo` перед
командой. Резервные копии находятся в `~/malevich-backups/ДАТА-ВРЕМЯ/`. При
проблеме после записи основной прошивки выведет команду отката.

## Панель и USB-разъём

Установщик копирует полную поддержку панели в `~/panel`, подключает host-драйвер
к Klipper и устанавливает:

```ini
[display]
lcd_type: malevich_panel
encoder_steps_per_detent: 4
panel_reverse_encoder: False
contrast: 239
invert: False
```

Разъём USB на LCD подключён к PB14/PB15 STM32 и +5 В; имена линий добавлены в
карты выводов X и XL. Эта версия пока не монтирует флешки: в прошивке Klipper
нет USB Host/MSC и транспорта передачи файлов с MCU в каталог `gcodes` на
Raspberry Pi. Для полноценной поддержки нужен драйвер USB Host, MSC/SCSI и FAT,
а также интерфейс передачи/копирования файлов. Одних алиасов пинов недостаточно.

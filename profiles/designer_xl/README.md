# Designer XL

Профиль XL хранится отдельно от X:

- `printer.cfg` — оси, нагреватели и периферия;
- `board_pins.cfg` — карта платы и линии LCD USB;
- `macros.cfg` — макросы и homing override;
- `firmware/designer_xl/klipper.bin` — отдельный путь для образа XL.

Для запуска XL-профиль временно использует `watermark` для экструдера (`max_delta: 1.0`) и стола (`max_delta: 2.0`), так как PID-калибровок XL пока нет. Перед печатью выполните `PID_CALIBRATE` отдельно для `extruder` и `heater_bed`, затем `SAVE_CONFIG`.

`position_endstop` оси Z задан как `0.465` по профилю Designer X. Проверьте это значение на механике XL перед движением оси и печатью.

Банки TMC2209 выбираются штатным Klipper через `select_pins`: PC3 выбирает
основной банк, `!PC3` — второй. Поэтому патч драйвера TMC UART не нужен.

В приложенном черновике XL описаны четыре Z-драйвера с адресами 0–3. AutoDetect
v0.6 проверяет во втором банке только адреса 0, 1 и 3. Установщик сообщает об
этом расхождении и спрашивает отдельное подтверждение перед заменой активного
конфига. STEP/DIR второго Z-блока также требуют проверки на конкретной плате.

USB разъём LCD подключён к PB14/PB15. В конфигурацию добавлены только имена
линий: USB Host/MSC стек и мост передачи файлов на Raspberry пока не реализованы.

## DIAG Guard

Основной автоустановщик Malevich добавляет общий host-side DIAG Guard, если активен
этот профиль: X, Y и экструдер используют TMC2209, а X/Y настроены на sensorless
homing через `diag_pin`. Модуль следует настройке pin в Klipper и не содержит
жёстко заданных GPIO. На совместимых платах DIAG/INDEX общие для драйверов кроме
Z; Guard проверяет X/Y/E и не меняет Z. Для другого принтера с той же платой можно
использовать тот же алгоритм через `--keep-config`, если его pin-map задан правильно.

Guard устанавливается в Klipper host Python/config и не меняет STM32 BIN: профиль
продолжает использовать Malevich v0.2.0.

При выборе XL автоустановщик также копирует host-файл `malevich_xl_z_probe.py`.
Он остаётся неактивным, пока в пользовательском конфиге нет `[malevich_xl_z_probe]`;
установщик не переносит примеры G28 и калибровочные пороги в конфиг. Для работы
нужен установленный host `trigger_analog.py`, а примеры порогов и хода нужно
перекалибровать под свою механику. Отключить копирование можно параметром
`--skip-xl-z-probe-module`. Новая прошивка MCU для него не собирается и не ставится.
